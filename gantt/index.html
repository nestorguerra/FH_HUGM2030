Su hoja de ruta, editable

El punto de partida conserva el calendario base del informe V1.1: 11 filas y 23 fases. Las fechas se expresaban por trimestre; ahora puede afinarlas. Los responsables están sin asignar y el color de una fase no acredita ejecución.

  • Pulse ＋ junto a una iniciativa para desplegar sus fases.
  • Pulse una fila o barra para editar fechas, responsables, notas y dependencias.
  • Arrastre una barra para moverla, o sus extremos para cambiar la duración. Un proyecto mueve también todas sus fases.
  • Arrastre el fondo del calendario, use las flechas o el desplazamiento de su ratón para recorrerlo. Los botones de zoom conservan el centro de la vista.
  • Haga doble clic en un espacio vacío del calendario para crear una tarea en esa fecha.
  • Con una barra enfocada, las flechas la mueven un día; Mayús mueve siete y Alt cambia el final. Enter abre su ficha.
  • Ctrl/⌘ Z deshace; Ctrl/⌘ Mayús Z rehace.

Sus cambios se guardan en este navegador. No se envían al hospital ni se sincronizan entre equipos. Descargue una copia JSON para recuperarlos o trasladarlos. El CSV sirve para abrir la tabla en una hoja de cálculo.
